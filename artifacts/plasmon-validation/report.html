Planar plasmon: numerical and physical validation

Two half-spaces: vacuum | passive Drude metal. This is an illustrative analytical metal, not a fit to gold or silver. Time convention exp(−iωt); propagation exp(+iβz). The complex-wavevector and complex-frequency plots are different real-axis slices of the same dispersion surface, not interchangeable inverses at finite loss.

What was run: 33 public APM discovery/refinement solves at real frequency, 33 at real wavevector, two additional solves for the characteristic maps, plus five local TE controls per case. Analytical roots place the small benchmark charts and select exterior branches; the markers are independent numerically accepted solver roots, not values copied from the formula. These charts do not demonstrate blind global discovery.

Independent equations and acceptance checks

Let u=ω/ωp and v=β/kp. εm=1−1/[u(u+iη)], η=0.02. At real u, v=u sqrt[εm/(1+εm)], with the passive forward sign. At real v the physical root obeys u⁴+iηu³−(1+2v²)u²−2iηv²u+v²=0, selected continuously from the positive lossless bound branch. The unsquared TM boundary condition κd/εd+κm/εm=0 is checked independently at each accepted point, with Im κd, Im κm positive. Transfer2 and Scatter2 checked values are compared at every root. The two half-spaces are used unchanged in both numerical paths.

Interpretation limits

The eigenvalues and exterior decay support the physical SPP interpretation for this benchmark. The built-in named dielectric classifier deliberately marks negative-permittivity exteriors unsupported, and explicit complex anchors retain unspecified built-in radiation provenance. We checked the bound physical branch independently; we did not manufacture a verified-positive-dielectric anchor, classify metal modes with the paper's dielectric labels, compute fields/QNM normalization, certify arbitrary materials or establish global mode coverage. TE controls only test the listed local windows.

Reproduce

From the lamina-core repository, with the Rust development environment loaded:

cargo run --release --manifest-path artifacts/plasmon-validation/Cargo.toml --locked --offline -- artifacts/plasmon-validation
python artifacts/plasmon-validation/plot.py

Plotting requires NumPy and Matplotlib. Raw CSVs, Rust/Python source, the local Cargo manifest/lockfile and PNG/PDF/SVG figures are included. The implementation uses public lamina-mode API imports. No solver/library source was changed.

Benchmark background: COMSOL's metal–dielectric interface derivation (TM boundary condition, evanescence and TE exclusion).
